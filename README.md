# Galaxy Deal Qualifier

A single-page quoting aid for retail consultants: pick a device and every deal it qualifies
for is worked out, stacked and totalled, with trade-in, New Galaxy Club, ECO bundles and
payment plans.

Not an official Samsung system. Always confirm the final price in POS.
